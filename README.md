# 产品雷达

一个用公开数据快速分析 App、App Store 游戏与 Steam 游戏市场的本地工作台。目标不是预测收入，而是在开发前识别需求、体验缺口、付费信号与竞争强度，减少盲目试错。

支持保留关键词搜索，并叠加近 30 天、90 天、180 天、1 年或全部时间筛选。时间范围按首次发布或最近更新时间判断产品活跃度。

关键词可以留空：此时 Apple 使用免费与付费公开榜单，Steam 使用热销与新品公开榜单，展示整体市场样本及其后续趋势；输入关键词时仍执行原有的细分市场搜索。

每次分析会在 `data/market-snapshots/` 保存同一查询条件的轻量快照。至少积累两个间隔 6 小时的快照后，系统会展示评论增长、搜索位置变化、上升与下降产品以及趋势折线；历史不足时只显示基线，不伪造趋势。

## 当前数据源

- Apple 官方 iTunes Search API：按关键词和国家搜索 App Store 应用与游戏，获取评分、评论数、价格、分类和发布日期等字段。游戏模式会增加游戏语义并过滤非游戏结果。
- Steam 商店公开端点：按关键词和国家获取游戏候选，并补充产品详情、价格、发布日期以及好评/差评统计。Steam 商店端点并非稳定的正式开发者契约，字段变化会通过数据源状态呈现。

## 评分边界

机会分只用于方向初筛，不是收入预测。公开市场数据不包含获客成本、留存、利润和团队执行力。获得候选方向后，仍应阅读差评、访谈用户，并优先用人工服务或低成本原型验证。
