# 咖啡冲煮记录 App 竞品分析报告

> 日期：2026-05-17
> 范围：国内外咖啡冲煮记录 & 品鉴管理类 App

---

## 一、市场背景

### 1.1 精品咖啡市场高速增长

| 指标 | 数据 |
|---|---|
| 全球精品咖啡市场规模（2024） | $270 亿 - $530 亿（来源不同） |
| 全球精品咖啡市场 CAGR | 8% - 12% |
| 中国精品咖啡市场规模（2024） | **279 亿元**（含零售口径） |
| 中国精品咖啡市场 CAGR（近 5 年） | **22.7%** |
| 中国咖啡消费人口 | 3,200 万+，同比增长 35.8% |
| 人均年咖啡消费 | 16.74 杯（2023），较 2016 年增长 86% |
| 精品咖啡门店数 | 6.8 万家，占总咖啡门店 27.9% |

**结论：精品咖啡处于爆发增长期，消费人群快速扩大，"记录工具"的需求随人群成熟自然增长。**

### 1.2 目标用户画像

- **核心年龄**：18-39 岁（25-39 岁为增长最快群体）
- **核心城市**：上海、北京、深圳、广州、杭州
- **性别**：女性为主力消费群体
- **消费习惯**：78.7% 每周至少饮用一次咖啡
- **购买动机**：提神醒脑（功能性）> 解馋愉悦（精神性）
- **APP 目标用户**：家庭手冲爱好者、精品咖啡豆订阅用户、入门进阶者、咖啡师/从业者
- **目标人群规模预估**：约 300-600 万人（占咖啡消费人群 10-20%）

## 三、核心竞品深度分析

### 3.1 享咖小记 — 国内最强竞品

**基础信息**
- 开发者：享时科技（王喆）
- 平台：iOS + Android（小米、华为等应用商店）
- App Store 评分：**4.6**（245 条评分）
- 包体：iOS 120.6MB / Android 136.7MB
- 更新频率：活跃（2025-12 月更新 v3.7.16）

**功能矩阵**

| 功能 | 支持情况 |
|---|---|
| 冲煮参数记录 | 水温、粉水比、研磨度、萃取时间等 |
| SCAA 杯测评分 | 11 维度（干/湿香气、风味、余韵、酸质、醇厚度、一致性、平衡度、干净度、甜度、综合评价、瑕疵扣除） |
| 风味轮 | 内置 SCAA 标准风味轮 |
| 咖啡感官词典 | 内置专业术语词典 |
| AI 优化建议 | 根据参数 AI 给出改善建议 |
| AI 识图 | 扫描咖啡包装自动录入 |
| 咖啡豆管理 | 品名、产地、产季、工艺、豆种、烘焙度、风味、处理站、等级、海拔、密度等 |
| 冲煮器具管理 | 4 大类（注水滴滤、完全浸泡、过滤式、浓缩），自定义参数 |
| 磨豆机管理 | 支持不同器具的研磨设置 |
| 金杯计算器 | 浓度 + 萃取率计算 |
| 费用追踪 | 记录咖啡开销，消费趋势分析 |
| 数据统计 | 周/月/年维度，使用次数、豆种、冲煮方式 |
| 打卡功能 | 每日冲煮记录打卡日历 |
| 配方分享 | 冲煮方案分享与交流 |
| 快捷指令 | iOS 快捷指令集成 |

**商业模式**
- 免费 + 订阅
- 连续包月：¥8（约 $1.1）
- 连续包年：¥78（约 $10.7）
- 一次性买断：¥198（约 $27.3）
- 额外流量包：¥3-8

**优劣势**
- 优势：功能最全面，SCAA 专业度最高，AI 功能领先国内竞品
- 劣势：功能堆砌感强，入门门槛高，UI/UX 一般（来自用户反馈），无社区/社交

**基础信息**
- 开发者：陈嘉敬
- 平台：iOS + Android（华为、VIVO、应用宝）
- 评分：Android 8.5（500+ 评价），App Store 无足够评分
- 下载量：约 886（应用宝数据）
- 包体：Android 78-148MB（版本差异大）
- 更新频率：活跃（2026-04 v4.1.0）

**功能矩阵**

| 功能 | 支持情况 |
|---|---|
| 冲煮参数记录 | 产地、庄园、烘焙度、处理法、器具、研磨度、水温、粉水比、时间 |
| 风味评价 | 6 维度（醇厚度、甜感、酸质、余韵、苦味、整体风味） |
| 咖啡统计 | 累计冲煮次数、豆种、总克数、总时长、频率 |
| 咖啡地图 | 记录/发现咖啡店（地图模式） |
| 咖啡赛事 | WBC、WLAC 等赛事资讯 |
| 咖啡知识库 | 原产地、处理法、豆种、风味解析、冲煮方式、萃取技巧 |
| 咖啡拉花教程 | 教学视频 |
| 冲煮攻略 | V60、法压、虹吸、爱乐压等 |
| 器具指南 | 磨豆机、手冲壶、滤杯等图文+视频 |
| 咖啡制作 | 拿铁、美式、冷萃等调配教程 |

| 咖啡因摄入管理 | 摄入量计算与统计 |

**商业模式**
- **完全免费**，无订阅、无内购

**优劣势**
- 优势：内容最丰富（教程+知识库+赛事），社区功能完善，完全免费
- 劣势：记录功能深度不足（6 维评分 vs SCAA 11 维），专业化程度低于享咖小记，更像"咖啡百科社区"而非"个人笔记工具"

### 3.4 国际竞品参考：HomeBarista

**最关键的国际对标产品**，功能最全面的咖啡追踪器。

**核心亮点**
- 25+ 冲煮参数
- AI 扫码自动录入豆信息
- 实时库存管理（自动扣减、补货提醒）
- 萃取率计算器（TDS → 萃取率）
- 意式浓缩调优助手
- 30+ 冲煮设备支持
- 多维度风味评分（酸度、醇厚度、余韵、香气、甜度、苦味，各 1-10）
- 综合评分 0-100
- 数据可视化（周/月/年趋势图、产地地图）

**商业模式**
- 免费试用 → Pro 订阅
- 3 天免费试用
- Pro 含 5 个专业工具

**优劣势**
- 优势：功能深度最强，专业感强，AI 集成度高
- 劣势：仅 iOS，仅英文，中国用户不友好

## 六、SWOT 总结

### 享咖小记
- **S**：功能最全面，SCAA 专业度最高，用户基础最大
- **W**：功能堆砌，UI 评价一般，无社交/社区，iOS UI 审美不足
- **O**：AI 方向可深入，社区化可做
- **T**：咖啡猎人免费策略、新兴竞品增多

### 咖啡猎人
- **S**：社区 + 内容生态最完善，完全免费，多平台
- **W**：记录功能深度不足，更新似乎缓慢，商业化缺失影响长期发展
- **O**：可加强记录功能和商业化
- **T**：难以维持免费模式的长期质量

### 咖啡札记
- **S**：极简专注，隐私友好，开发者亲民
- **W**：用户量极小，功能太浅，无 AI 和分析
- **O**：快速增长品类中的早期入局者
- **T**：大厂或功能更全的产品挤压

### 国际市场整体
- **S**：功能深度强，开源选项多（Beanconqueror/Timer.Coffee）
- **W**：全部仅英文，无中文市场适配，UI 设计普遍偏工具化
- **O**：中国市场基本空白被满足
- **T**：中国市场产品专业化提升后可反向输出

## 七、市场机会与缺口总结

### 7.1 已有产品覆盖较好的领域
- 基础冲煮参数记录 — **红海**（所有竞品都有）
- SCAA 杯测评分 — **享咖小记独占**
- 咖啡知识库/教程 — **咖啡猎人独占**
- AI 识豆 — **享咖小记 + HomeBarista**

### 7.2 未被充分满足的需求（机会缺口）

| 缺口 | 说明 | 优先级 |
|---|---|---|
| **智能冲煮洞察** | 现有产品只记录不分析，缺乏"记录→数据→建议→改进"的闭环 | ★★★★★ |
| **口味成长曲线** | 无法看到自己的口味偏好随时间的变化趋势 | ★★★★ |
| **Web + 移动端** | 全部是 App 独占，没有 Web 端/桌面端查看分析 | ★★★★ |
| **离线优先** | 大部分需要联网，调酒吧台环境网络不一定好 | ★★★★ |
| **新手入门引导** | 享咖小记功能太复杂，咖啡猎人内容太多，缺少"简化版" | ★★★★ |
| **极简 10 秒记录** | 没有产品真正做到"快速记录"（咖啡札记目标在此但 UI 简陋） | ★★★★ |
| **社区（非百科）** | 咖啡猎人有社区但太重百科，缺少"晒单+交流"的轻量社区 | ★★★ |
| **咖啡豆溯源数据库** | 类似调酒笔记的 IBA 配方库，做一个"咖啡豆品种/产地数据库" | ★★★ |
| **订阅豆子追踪** | 每月收到不同豆子，追踪不同批次的口感和参数 | ★★★ |
| **连 Bluetooth 秤** | 仅 Beanconqueror/Filtru 支持，国内市场空白 | ★★★ |

### 7.3 差异化策略建议

**方向 A：做"最有洞察的咖啡笔记"（推荐）**
- 核心差异点：记录不是目的，**发现规律**才是
- 记录 30 杯后自动生成个人风味偏好报告
- "你的最佳萃取窗口" —— 针对你常喝的豆子类型
- 跨豆对比分析 —— 同一冲煮参数对不同豆子的影响
- 不同于"享咖小记"的功能堆砌，聚焦"数据 → 知识"的转化

**方向 B：做"最好用的咖啡笔记"（用户体验差异）**
- 核心差异点：10 秒完成一次记录，1 分钟完成深度品鉴
- 极简 UI，三档模式（快速/标准/专业）
- Web + PWA + 小程序多端覆盖
- 离线优先，数据完全本地

**方向 C：做"咖啡社区型笔记"（社交差异）**
- 核心差异点：记录 + 发现 + 交流，形成 UGC 闭环
- 晒冲煮方案、挑战每周主题
- 关注同好、围观其他人的调参过程
- 但社区冷启动难度大——建议从工具切入，逐步社区化

## 八、结论

| 评估维度 | 结论 |
|---|---|
| 市场规模 | 精品咖啡高速增长，目标人群 300-600 万且在扩大 |
| 竞争格局 | 有领先者但无垄断者，"记录工具"品类尚未形成品牌认知 |
| 差异化空间 | 大——智能洞察、Web 端、UX 设计都是明显缺口 |
| 风险 | 品类天花板相对有限，需要结合付费订阅验证 PMF |
| 建议 | **优先考虑做面向手冲爱好者的"智能冲煮教练"**，而非又一个参数记录工具 |
